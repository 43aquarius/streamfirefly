# StreamFirefly 1.0.8

这一版让资源列表更好找：正在看的视频排在最前面，文件大小和预览图也显示得更完整；缓存捕捉生成大视频不再中途失败，另外修复了几个下载和录制中的问题。

## 改进：正在看的视频排在最前面

打开流萤时，页面上正在播放的视频会排到资源列表最上面，带“当前视频”标签；能下载的对应资源也会一起排在前面。先打开流萤再播放也一样，播放一小会儿后就会排上去。滚动页面经过自动播放的视频不会让列表来回跳；手动选了按大小或时长排序时不会置顶。（[#12](https://github.com/rumoii/streamfirefly/issues/12)）

## 改进：更少“大小未知”

X 等网站的很多视频以前显示“大小未知”，现在流萤会自动读出文件大小。资源的“发现来源”也按实际位置显示，不再都写成“页面脚本”。

## 改进：预览图完整显示

列表里的缩略图不再裁切，能看到整张封面；点开后的预览区域也加高了，竖屏视频不会只剩窄窄一条。

## 改进：缓存捕捉生成大视频不再超时

录完后生成视频文件以前最多只给 2 分钟，大文件或硬盘较慢时会被中途停掉。现在只要还在推进就会一直等，生成时显示第几段、已处理多少和百分比；生成前会检查硬盘剩余空间，空间不够时保留录制数据，腾出空间后可以重新生成。

在 YouTube 录制时，建议先关掉播放器的“自动播放”，以免录完后接着录进下一个视频。

## 修复

- 下载字幕时不会再覆盖保存目录里已有的同名文件。下载 HLS 视频也不再在系统盘上多占一份完整视频的空间。（[#7](https://github.com/rumoii/streamfirefly/issues/7)）
- 设置了自定义代理时，重启浏览器后自动继续的下载也会走代理。（[#8](https://github.com/rumoii/streamfirefly/issues/8)）
- 关闭浏览器时，正在进行的录制会正确记为“已中断”，不会留下仍在运行的生成进程。（[#9](https://github.com/rumoii/streamfirefly/issues/9)）
- 悬浮窗口较窄时，设置页的分类导航不再被拉得很高。（[#6](https://github.com/rumoii/streamfirefly/issues/6)）
- 在 YouTube 等网站缓存捕捉时，明明录到了内容，却提示“录制期间视频没有加载新内容”、生成不了文件。现在能正常生成；之前这样失败的记录，升级后点“重新生成文件”就能恢复。

## 升级

扩展和本地助手都有改动，请一起升级到 1.0.8：按 [INSTALL.md](https://github.com/rumoii/streamfirefly/blob/main/INSTALL.md) 的「升级」一节，把新扩展覆盖到原来的文件夹并重新加载，再在流萤设置页复制安装命令运行一次。

**第一次安装？** 请按 [安装指南（INSTALL.md）](https://github.com/rumoii/streamfirefly/blob/main/INSTALL.md) 操作：先装浏览器扩展，再一键安装本地下载助手
